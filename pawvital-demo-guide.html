Section 2

Install the Theme

1
Go to Online Store → Themes In your Shopify Admin sidebar, click Online Store, then Themes.
2
Upload the theme zip Scroll down to Theme library → click Add theme → Upload zip file → select pawvitalthemev14.zip.
3
Preview then Publish Once uploaded, click Preview to check the theme, then click Publish to make it live.
4
Verify it's active The theme should now appear at the top of the Themes page with a green Current theme label.
Tip: If Shopify shows errors during upload, make sure you're using the exact zip file provided — do not re-zip the folder yourself as the file structure must be at root level.
Section 3

Install Matrixify

1
Open the Shopify App Store In Shopify Admin → Apps → Shopify App Store.
2
Search for "Matrixify" Find the app by Excelify (formerly Excelify). It is free to install for basic imports.
3
Click Install Accept the permissions. Matrixify will appear under Apps in your admin.
The free Matrixify plan supports importing up to 10 products per import. The PawVital demo has 8 products, so the free plan is sufficient. For re-importing or updating larger stores, a paid plan may be needed.
Section 4

Upload Demo Content

All demo content — products, collections, pages, blog posts, and navigation — is contained in a single Excel file.

1
Open Matrixify Shopify Admin → Apps → Matrixify.
2
Click "Import" On the Matrixify home screen, click the Import button.
3
Upload the Excel file Click Choose file → select pawvital-matrixify.xlsx → click Import.
4
Wait for completion Matrixify shows a live progress screen. Images are fetched from Unsplash CDN during import — this can take 2–5 minutes depending on internet speed.
5
Check the results When complete, Matrixify shows a summary. Click View results to see any errors. Green rows = success.
Tip: If any rows show errors, they are usually image fetch failures. Simply run the import again — Matrixify skips already-imported rows and retries failed ones.

Section 6

After Import — Theme Setup

Once Matrixify finishes, configure the theme sections in the Shopify Customizer.

Open the Customizer

Shopify Admin → Online Store → Themes → click Customize next to PawVital.

Homepage Sections

SectionWhat to Set
Announcement BarEdit the 3 marquee messages (shipping, vet-formulated, subscribe & save)
HeroUpload a hero image (1200×800px recommended), set heading and CTA button link
Featured CategoriesSelect up to 6 collections from the imported ones
Featured CollectionSelect Best Sellers or All Products
Benefit BandUpload a product lifestyle image, edit the 4 benefit points
Subscription CTAEdit headline and link to /pages/subscriptions
TestimonialsEdit the 3 customer review cards
NewsletterConnect to your email provider or Shopify Email

Header Settings

1
Set the main menu In Header settings → Menu → select Main menu (imported by Matrixify).
2
Upload logo (optional) The theme ships with the PawVital SVG logo. Upload a custom logo under Header → Logo image.
3
Set mega menu featured image Under Header → Mega menu featured column — upload an image and set the CTA link to /collections/bundles.

Footer Settings

In the Customizer → Footer section, select Footer menu as the navigation source. The footer is pre-structured with SHOP, LEARN, and SUPPORT columns matching the imported menu.

Tip: Save the Customizer frequently using the Save button at the top right. Changes are not auto-saved.
Section 7

Managing Content After Import

Editing Products

1
Go to Products Shopify Admin → Products → click any product name.
2
Edit title, description & pricing Use the rich text editor for description. All benefit bullets display as a bulleted list in the product accordion.
3
Add/replace images Drag & drop images in the Media section. The first image becomes the main product photo. Recommended size: 1000×1000px square.
4
Manage variants Under Variants → edit price, compare-at price, SKU, and inventory for each size/option.

Editing Collections

1
Go to Products → Collections Click any collection to edit title, description, image, and sort order.
2
Smart collections auto-populate Collections like Joint & Mobility use rules (e.g. tag = joint). Products with matching tags appear automatically.
3
Collection images Click Add image in the collection editor, or re-import via Matrixify with updated image URLs.

Editing Pages

Shopify Admin → Online Store → Pages. Click any page (About, Contact, FAQ, etc.) to edit the content using the rich text editor. All page content renders with proper line-height and heading spacing via the theme's RTE styles.

Editing Blog Posts

Shopify Admin → Online Store → Blog posts. Click any article to edit the title, content, featured image, and tags. New articles are published immediately unless you set a future publish date.

Do not delete the "PawVital Blog" blog channel — only delete individual articles. Deleting the blog itself removes the blog page from the store.

Section 9

Common Issues & Fixes

IssueCauseFix
Matrixify shows image errors Unsplash CDN timed out during import Re-run the import — Matrixify retries failed images automatically
Collections are empty after import Smart collection rules use tags not yet on products Check that products have the correct tags (e.g. joint, calm, skin)
Homepage shows "No content" Customizer sections not configured yet Open Customizer → add sections and select collections/products
Menu shows wrong links Main menu not selected in Header settings Customizer → Header → Menu → select Main menu
Checkout goes to homepage Store password protection enabled Shopify Admin → Online Store → Preferences → disable password
Theme not showing after upload Theme not published Online Store → Themes → click Publish next to PawVital
Product page 404 Product handle mismatch Shopify Admin → Products → check the URL handle matches the collection link
Cart shows 0 items after adding Browser cookie blocked Disable browser extensions / try incognito mode

Matrixify Import Tips

  • Always import products before collections (collections depend on product tags)
  • Use the MERGE command (already set in the Excel file) to avoid duplicate products on re-import
  • If you see a "rate limit" error, wait 60 seconds and click Continue in Matrixify
  • Check the Results tab after every import — green = success, red = needs attention
  • Matrixify preserves existing content — it only updates rows included in the file
Never use "DELETE" command in Matrixify unless you intend to permanently remove content. This action cannot be undone.
Section 10

Quick Reference Checklist

Use this checklist to confirm everything is set up correctly before handing the store to your client.

Theme & Content

  • PawVital theme uploaded and published
  • Matrixify import completed with no errors
  • All 8 products visible in Shopify Admin → Products
  • All 14 collections visible in Shopify Admin → Collections
  • 5 pages visible in Online Store → Pages
  • Blog posts visible in Online Store → Blog posts
  • Main menu and Footer menu imported correctly

Theme Customizer

  • Header → Menu set to "Main menu"
  • Hero section has image, heading, and CTA link
  • Featured Categories section shows 6 collections
  • Featured Collection section linked to a collection
  • Footer menu set to "Footer menu"
  • All sections saved in Customizer

Store Settings

  • Password protection disabled (Online Store → Preferences)
  • Shipping zones configured (Settings → Shipping)
  • Payment provider connected (Settings → Payments)
  • Store currency set correctly (Settings → Store details)
  • Contact email set (Settings → Store details)

Test Before Go-Live

  • Add a product to cart and complete a test order
  • Test on mobile — check product page, cart, and checkout
  • Test search — search for "joint" and "calm"
  • Test product page accordions (Description, Shipping, Ingredients)
  • Test cart drawer — add, change quantity, remove, checkout
  • Verify all collection pages show products
  • Verify Contact page loads correctly
Support: For theme-related issues, refer to the theme files in the GitHub repository. For Matrixify questions, visit help.matrixify.app. For Shopify platform issues, contact Shopify Support via your Admin dashboard.
