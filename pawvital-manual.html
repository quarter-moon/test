Chapter 1

Shopify Admin — Getting Your Bearings

Your Shopify Admin is at your-store.myshopify.com/admin. This is where you manage everything.

Key Areas You'll Use Most

Products Section

Everything under Products in the sidebar:

  • Products — add/edit items
  • Collections — group products
  • Inventory — stock levels
  • Gift cards

Online Store Section

Everything under Online Store:

  • Themes — install & customize
  • Blog posts — articles
  • Pages — static pages
  • Navigation — menus
  • Preferences — SEO, password
Bookmark tip: Open your Shopify Admin in one tab and your live storefront in another. After making changes, refresh the storefront tab to see them instantly.

Understanding the Theme Customizer

The Customizer is a visual editor for your homepage and theme settings. To open it:

Online Store → Themes → Customize

The Customizer has:

  • Left panel — list of sections you can click to edit
  • Center preview — live preview of your homepage
  • Top bar — switch between Desktop / Mobile / Tablet view
  • Save button — always click Save after making changes
Important: Changes in the Customizer are NOT saved automatically. Always click the Save button at the top right before leaving.
Chapter 2

Adding Products

Products are the core of your store. Follow these steps to add each product manually.

Products → Add product

Step-by-Step: Add a Product

1
Product title Enter the product name, e.g. "Hip & Joint Chews for Dogs". Keep it clear and searchable.
2
Description Write a description using the rich text editor. Use bullet points for key ingredients or benefits. This text appears in the product page accordion.
3
Add images Drag & drop product photos into the Media section. Recommended: 1000×1000px square, JPG or PNG. The first image becomes the main photo.
4
Set pricing Enter the Price. Optionally enter a Compare-at price (the original price shown crossed out — creates a "Sale" badge automatically).
5
Inventory & SKU Enter a SKU (your internal code, e.g. PV-JOINT-30). Set Track quantity and enter stock count. If you don't track inventory, uncheck it.
6
Shipping weight Under Shipping, enter the product weight. This is used to calculate shipping rates at checkout.
7
Add variants (if needed) If your product comes in different sizes or flavors, scroll to Variants → click Add options like size or color → enter option name (e.g. "Size") and values (e.g. "30 count, 90 count").
8
Add product tags Tags are used by Smart Collections to auto-group products. Add relevant tags separated by commas, e.g. joint, supplement, dog, senior.
9
Set product type & vendor In the right sidebar, enter Product type (e.g. Supplement) and Vendor (e.g. PawVital).
10
Save the product Click Save at the top right. The product is now live if your store is published.

Chapter 3

Creating Collections

Collections group products together. There are two types: Manual (you pick products) and Smart / Automated (products added automatically by rules).

Products → Collections → Create collection

Type 1 — Manual Collection

You choose exactly which products appear. Good for: Best Sellers, Bundles, Sale, New Arrivals.

1
Enter collection title E.g. "Best Sellers" or "Bundles & Sets".
2
Set Collection type to Manual Under Collection type, select Manual.
3
Add products Scroll to the Products section → click Browse → search for and select products → click Add.
4
Add a collection image Scroll to Collection image → click Add image → upload a photo. Recommended: 800×800px.
5
Save Click Save. The collection is now live at /collections/best-sellers.

Type 2 — Smart (Automated) Collection

Products are added automatically based on rules like tags, price, or product type. Good for: Joint & Mobility, Calm & Anxiety, Supplements, Dental.

1
Enter collection title E.g. "Joint & Mobility".
2
Set Collection type to Automated Under Collection type, select Automated.
3
Add a condition / rule Click Add condition → select Product tag → is equal to → type joint. Products tagged joint will appear here automatically.
4
Add collection image & save Upload an image and click Save.

Chapter 4

Setting Up Navigation Menus

Menus control what links appear in your header and footer. You need to set up two menus: Main menu and Footer menu.

Online Store → Navigation

Setting Up the Main Menu

1
Click "Main menu" You'll see Shopify's default links. Delete any you don't need by clicking the trash icon.
2
Add a menu item — click "Add menu item" Enter a Name (what shows in the nav) and a Link (where it goes).
3
Link to a collection In the Link field, click the dropdown → select Collections → choose your collection. E.g. Link "Shop" to All Products.
4
Add sub-menu items (dropdown) Drag a menu item slightly to the right to make it a child of the item above. This creates a dropdown sub-menu.
5
Save menu Click Save menu. Your changes are live immediately.

Creating Pages

Online Store → Pages → Add page

Step-by-Step: Create a Page

1
Enter the page title E.g. "About Us". Shopify auto-generates the URL handle (slug) from the title.
2
Write the content Use the rich text editor. You can add headings (H2, H3), bold text, bullet lists, and links. The PawVital theme styles these beautifully with proper spacing.
3
Set visibility Under Visibility on the right, set to Visible so the page is publicly accessible.
4
Save Click Save. The page is now live at its URL (e.g. /pages/about).
5
Add the page to your menu Go to Online Store → Navigation → Main menu or Footer menu → Add menu item → Link → Pages → select your page.
Contact page tip: The Contact Us page in the demo has pre-written content with Customer Service info. You can copy that content structure and replace the placeholder details with real ones.

Policy Pages (Auto-generated by Shopify)

Shopify can auto-generate policy pages (Privacy Policy, Terms of Service, Refund Policy) under:

Settings → Policies

Click Create from template for each policy, edit as needed, and Save. These are separate from regular pages and appear in the checkout footer automatically.

Setting Up the Blog

The blog builds trust and drives organic traffic. PawVital uses a blog called "PawVital Blog".

Online Store → Blog posts → Create blog post

Step-by-Step: Create a Blog Post

1
Enter the post title E.g. "5 Signs Your Dog Needs a Joint Supplement".
2
Write the content Use headings (H2, H3), paragraphs, and bullet lists. Aim for 400–800 words per article.
3
Add a featured image On the right side, click Featured image → upload. Recommended: 1200×630px. This image appears in blog listing pages and social previews.
4
Select or create a blog Under Blog on the right → select PawVital Blog. If it doesn't exist yet, type "PawVital Blog" and click Create a new blog "PawVital Blog".
5
Add tags Add topic tags like dogs, joints, supplements. These help with filtering on the blog page.
6
Set visibility and publish Set to Visible and click Save. The post is live immediately at /blogs/pawvital-blog/post-title.

Chapter 8

Store Settings

Before going live, configure these essential settings. Find them all under Settings in the sidebar.

Store Details

Settings → Store details
  • Store name: PawVital
  • Contact email: your real support email
  • Store currency: USD (or your local currency)
  • Store address: required for tax calculations
  • Time zone: set to your local time zone

Payments

Settings → Payments
  • Enable Shopify Payments (accepts all major cards) — requires bank account
  • Add PayPal as an alternative method
  • Optionally add Shop Pay, Apple Pay, or Google Pay

Shipping

Settings → Shipping and delivery
  • Add shipping zones (e.g. "United States")
  • Add rate: Free shipping with minimum order $49
  • Add rate: Standard shipping — flat rate $5.99 (under $49)
  • Optionally add Express shipping with a higher rate

Taxes

Settings → Taxes and duties
  • Enable Charge taxes on shipping rates if required by your location
  • Shopify auto-calculates tax rates for most regions

Notifications (Emails)

Settings → Notifications
  • Customize order confirmation, shipping, and refund email templates
  • Add your store logo and brand colors to email templates

Domain

Settings → Domains
  • Buy a custom domain through Shopify (e.g. pawvital.com) or connect one you already own
  • Set your custom domain as the Primary domain

Disable Password Protection

Online Store → Preferences → Password protection

New Shopify stores have password protection ON by default. Uncheck "Restrict access to this online store" and save when you're ready to go live.

Do not go live until payments and shipping are configured. Customers could place orders that you can't fulfill or charge incorrectly.
Chapter 9 — Optional

Matrixify Bulk Import Shortcut

Instead of adding products, collections, pages, and menus manually one by one — you can import everything at once using a single Excel file and the Matrixify app.

When to use Matrixify: Use it when you want to set up the store quickly with all demo content pre-filled. You can always edit everything after import. Skip this chapter if you prefer to set up the store manually using Chapters 2–6.

What Matrixify Does

The pawvital-matrixify.xlsx file contains pre-built sheets for every content type. Matrixify reads the file and creates everything automatically — including fetching images from the internet.

SheetCreatesCount
ProductsAll 8 products with images, variants, tags, descriptions8
Smart CollectionsAuto-collections with rules10
Custom CollectionsManual collections (Best Sellers, Bundles, etc.)4
PagesAbout, Contact, FAQ, Shipping, Subscriptions pages5
Blogs / Articles4 blog posts with images4
MenusMain menu + Footer menu with all links2

Step 1 — Install Matrixify

1
Open Shopify App Store Admin → Apps → Visit Shopify App Store → search "Matrixify".
2
Install the app Click Add app → accept permissions. The free plan allows up to 10 products per import — enough for the demo.

Step 2 — Import the Excel File

1
Open Matrixify Admin → Apps → Matrixify.
2
Click "Import" Click the Import button on the main screen.
3
Upload pawvital-matrixify.xlsx Click Choose file → select the Excel file → click Import.
4
Wait for completion Matrixify shows live progress. Takes 2–5 minutes. Images are fetched automatically from the internet.
5
Check results When done, click View results. Green = success, red = error. If any images failed, re-run the import — Matrixify retries failed ones.

After Matrixify Import

Matrixify creates all the products, collections, pages, and menus. You still need to:

  • Go to the Customizer and configure homepage sections (Chapter 7)
  • In Header settings → select Main menu
  • Replace placeholder images with real product photos
  • Edit page content with your real business information
  • Configure store settings (payments, shipping) — Chapter 8
Time saved: Manual setup (Chapters 2–6) takes approximately 2–4 hours. With Matrixify, the same content is imported in under 10 minutes.
Important: Run the Matrixify import on a fresh store (no existing products). If products already exist, the import uses MERGE mode — it will update matching products rather than create duplicates. This is safe, but check for unwanted changes afterwards.
Chapter 10

Go-Live Checklist

Before sharing the store URL with customers, go through this checklist to make sure everything is working correctly.

✅ Content

  • All products added with real photos, descriptions, and pricing
  • All product variants have correct prices and inventory set
  • All collections created and populated with products
  • Main menu and Footer menu configured correctly
  • All pages created: About, Contact, FAQ, Shipping, Subscriptions
  • Blog has at least 1 published post
  • No placeholder "Lorem ipsum" text anywhere on the store

✅ Theme & Homepage

  • PawVital theme published (shows as "Current theme")
  • Announcement bar has real messages
  • Hero section has a real image, heading, and working CTA button
  • Featured Categories section links to correct collections
  • Featured Collection shows real products
  • Testimonials have real (or realistic demo) reviews
  • Footer shows correct menu links and contact info

✅ Store Settings

  • Store name and contact email set correctly
  • Payment provider connected and tested
  • Shipping zones and rates configured
  • Tax settings reviewed for your region
  • Custom domain connected and set as primary
  • Password protection disabled
  • Policy pages created (Privacy, Refund, Terms)

✅ Testing

  • Add a product to cart — cart drawer opens and shows item
  • Change quantity in cart — total updates correctly
  • Click Checkout — proceeds to Shopify checkout page
  • Complete a test order using Shopify's Bogus Gateway (test payment)
  • Check order confirmation email arrives correctly
  • Open the store on a real mobile phone — no horizontal scroll
  • Test the search — searching "joint" returns products
  • Test product page accordions — open and close correctly
  • Test contact page — form submits and you receive the email

How to Place a Test Order

Settings → Payments → Manage → Use Bogus Gateway for testing

At checkout, use card number 1 and any future expiry date. This places a real test order with no actual charge. Cancel or delete the test order afterwards.
